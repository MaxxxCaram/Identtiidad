# Podcast Creator

Una aplicación web moderna para crear y editar podcasts para YouTube.y?

## Características

- Grabación de audio en tiempo real
- Visualización de forma de onda
- Editor de audio con controles de reproducción
- Interfaz moderna y responsiva
- Soporte para subir archivos de audio existentes

## Requisitos

- Node.js 18.0.0 o superior
- npm o yarn

## Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/MaxxxCaram/Identtiidad.git
cd Identtiidad
```

2. Instala las dependencias:

```bash
npm install
# o
yarn install
```

3. Inicia el servidor de desarrollo:

```bash
npm run dev
# o
yarn dev
```

4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Uso

1. **Grabación de Audio**

   - Haz clic en "Iniciar Grabación" para comenzar a grabar
   - Usa "Detener Grabación" cuando hayas terminado
   - Reproduce la grabación para verificar el audio

2. **Edición de Audio**
   - Sube un archivo de audio existente o usa una grabación reciente
   - Usa la barra de progreso para navegar por el audio
   - Reproduce/pausa el audio según sea necesario

## Tecnologías Utilizadas
