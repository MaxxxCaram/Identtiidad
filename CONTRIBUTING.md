# Contributing to Identtiidad

Thanks for your interest in contributing!

## How to contribute

1. Fork the repository
2. Create a new branch (`git checkout -b feature/nombre-feature`)
3. Make your changes
4. Commit your changes (`git commit -am 'Add new feature'`)
5. Push to the branch (`git push origin feature/nombre-feature`)
6. Create a Pull Request

## Guidelines

- Use clear, descriptive commit messages
- Keep code style consistent with the project
- Add tests or documentation as needed

---

If you have any questions, open an issue or contact the maintainers.
